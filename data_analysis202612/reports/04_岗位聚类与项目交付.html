0A. 【主线】先用二维例子理解“分配—更新”，再进入文本矩阵¶

KMeans反复执行：选中心 → 把每点分到最近中心 → 用群内均值更新中心。 它优化群内平方距离，不理解职位含义。特征的尺度、相似度定义和样本范围都会影响结果。 下面6条记录是人工构造的二维教学示例，不是模型对真实岗位的结论。

initial_centers = np.array([[0, 0], [8, 8]], dtype=float)
# 广播得到6×2×2差值：6个点、2个中心、2个坐标；沿坐标轴求平方和。
squared_distances = ((toy_points[:, None, :] - initial_centers[None, :, :]) ** 2).sum(axis=2)
# 每一行代表一个点到各中心的距离；argmin返回最近中心的列号，也就是群标签。
toy_labels = squared_distances.argmin(axis=1)
updated_centers = np.vstack([toy_points[toy_labels == group].mean(axis=0) for group in range(2)])

2. 比较 K=3、4、5、6，并检查稳定性¶

KMeans 将文本分成K群，最小化群内距离。固定种子让课堂结果可复现。 轮廓系数用于比较本次候选方案；分值低说明分群边界较弱，没有普适“合格线”。 同时检查最小群大小和两个随机种子下的 ARI（一致性指标，不是准确率）。 选择：优先保留最小群≥20且ARI≥0.6的方案，再取轮廓系数较高者；若无方案则回退并提示。 0.6是本课堂预设的稳定性筛选规则，不是行业通用标准。规则公开且可修改。 这只是起点，最终解释仍依赖代表文本审核。

3. 用关键词、代表岗位和公司集中度解释群¶

4C. 【主线】从“分群”到“检索”：按技能兴趣找到相近岗位¶

聚类是先给样本分群；检索是给定查询，按相似度排序。 输入“Python SQL 实验 因果推断 数据分析”，用训练时的同一词表与IDF转换，计算余弦相似度。 相似度只代表文本接近，不代表求职者适合度、匹配成功率或录用概率。

查询词全部不在词表时会得到零向量，此时必须提示改写查询，不能把任意岗位当推荐结果。

4D. 【拓展】不只看代表样本，还要看边界样本¶

到最近群中心距离较大的文本可能是离群岗位；第一、第二近中心距离差很小，说明归属模糊。 距离差只是诊断量，不是概率，也不能用“99%置信度”描述。 阅读这些岗位可以发现混合职责、词典不足或样本范围过宽，而不是只展示最漂亮的中心样本。

4E. 【课后拓展】入门监督学习：预测招聘入口编码，先战胜简单基线¶

聚类没有标签；分类需要标签。这里使用已有的society/campus编码做一个入门二分类实验， 研究问题是文本能否帮助区分本样本的招聘入口编码。这不是学历、岗位价值、是否能投递或个人录用预测。 campus中可能包含实习，标签来自数据入口编码，不能改称“正式工作与实习”的真值。

流程：固定子集 → 按相同处理后正文分组留出测试集 → 只在训练集fit TF-IDF → 逻辑回归 → 与多数类基线比较。 逻辑回归虽有“回归”二字，此处用于分类。测试集不能参与词表、IDF或模型参数学习。

指标 含义
Accuracy 全部预测中正确的比例；类别不平衡时可能误导
Precision 预测为某类的记录中，真实为该类的比例
Recall 真实为某类的记录中，被找回的比例
Macro-F1 先对每类算F1，再等权平均，避免大类完全主导结果

同文分组只能防止完全相同正文跨集合，不能完全消除近似模板泄漏。结果只限同一快照留出集， 没有验证新公司或未来数据；不要把较高分数写成对招聘市场的普遍预测能力。
