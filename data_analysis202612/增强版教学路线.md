# 注释增强版教学路线

课程仍是4×90分钟。增强不等于把所有内容塞进课堂：教材作为可运行参考书，课堂抓住主线，
其余实验用于教师选择或学生课后。建议学生一边读代码注释，一边修改一个变量验证理解。

## 第1课：从看懂表，到自己整理表

| 时间 | 课堂任务 | 应能解释的问题 |
|---|---|---|
| 0—15分钟 | 业务问题、观察单位、指标与维度 | 为什么职位数不等于招聘人数？ |
| 15—35分钟 | 字典/列表/类型、函数、DataFrame、布尔筛选、loc/iloc | 空值补0会产生什么偏差？ |
| 35—50分钟 | 一致快照，SQL与Pandas计数对照 | 为什么不直接复制正在写入的.db？ |
| 50—70分钟 | 单条JSON观察，再批量展开、验证身份、处理城市 | 字符串、字典、列表分别如何处理？ |
| 70—90分钟 | 脏数据小实验、质量表与导出 | 程序如何证明没有静默丢行？ |

选讲：一对多组织关联。课后：做一次安全merge，说明关联后行数与不同职位数的区别。
基础薄弱学生可以使用已生成快照；环境安装和依赖排错不占课堂核心时间。

## 第2课：先理解比较，再选择图表

| 时间 | 课堂任务 | 应能解释的问题 |
|---|---|---|
| 0—15分钟 | 手算一职位两城市，列指标分母 | 为什么城市覆盖率不要求合计100%？ |
| 15—35分钟 | 公司数量与公司内类型构成 | 数量和占比为何可能给出不同印象？ |
| 35—55分钟 | 城市展开、覆盖与平均分摊对比 | 同一份数据换口径后，数字如何变化？ |
| 55—70分钟 | 选择热力图或累计贡献图进行讲解 | “二八规律”究竟成立吗？ |
| 70—90分钟 | 北京社招下钻、结论卡、同伴检查 | 是比例变化还是百分点变化？ |

选讲/课后：统一社招/校招构成后的北京覆盖率。先讲分层与权重，不要求初学者记公式推导。
本课有8张参考图，课堂精讲其中4张即可；其余供替代口径练习，不是8张图全部逐行演示。

## 第3课：文本变成列，但列名不能夸大含义

| 时间 | 课堂任务 | 应能解释的问题 |
|---|---|---|
| 0—15分钟 | 文本清洗与词典正反例 | Java为什么不能命中JavaScript？ |
| 15—35分钟 | 0/1技能矩阵、职责/要求分开、提及率 | “没提到”为什么不等于“不需要”？ |
| 35—50分钟 | 宽长表、标题提示与技能画像 | 统计单位何时变成职位—技能关系？ |
| 50—65分钟 | SQL语境提示与命中证据 | “加分”“不要求”“熟悉”如何区分？ |
| 65—80分钟 | 3条示例手算TF-IDF，再看真实关键词 | 常见词的IDF一定等于0吗？ |
| 80—90分钟 | 人工检查10条，记录规则局限 | 只有命中正例能否计算召回率？ |

选讲/课后：Lift与Jaccard、学历经验覆盖率、完整公司比较热力图。
标题含实习但入口编码为campus/society，不必然是错误；保留两种信息做对照，不覆盖原编码。
标题提示类别的规则不自动扩展研究子集，学生应自行评估是否增加“经营分析”等候选关键词。

## 第4课：模型必须接受比较和反例检查

| 时间 | 课堂任务 | 应能解释的问题 |
|---|---|---|
| 0—15分钟 | 6个点的一次KMeans分配/更新 | 模型优化的是什么？ |
| 15—35分钟 | 字符失败基线、分词改进、K方案比较 | 为什么指标更高也可能不更有用？ |
| 35—50分钟 | 代表岗位、技能画像与类型分层 | 是岗位方向差异，还是模板/类型构成差异？ |
| 50—65分钟 | 修改查询词做相似岗位检索 | 相似度为什么不是适合度或录用率？ |
| 65—75分钟 | 阅读1条边界岗位，整理报告 | 到两个中心距离接近意味着什么？ |
| 75—90分钟 | 小组汇报、STAR与互相质疑 | 你独立验证了什么？ |

选讲：词典技能与全文TF-IDF聚类的表征比较。
**课后拓展**：监督学习入口编码分类。补充训练/测试、Pipeline、逻辑回归、Dummy基线、
Accuracy、Macro-F1和混淆矩阵；完全零基础班不要求在这节90分钟内完成。

## 教师使用建议

1. 上课前完整运行教材，课堂以“预测输出—运行—解释—改一个参数”为循环。
2. 不要逐字念注释：让学生先读注释，说出输入、输出、分母，再运行。
3. 每课至少让学生独立改一个条件或规则，而不是只按Run All。
4. 报告可以使用自动生成版作为参考，但独立作业必须换一个问题并保留自己的核验记录。
5. 检索和分类是不同研究任务，不能混淆；分类目标仅是已有入口编码，不代表能否投递或录用。
