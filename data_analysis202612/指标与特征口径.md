# 指标与特征口径

## 研究单位与范围

- 原始单位：固定SQLite快照中 `pending_jobs` 的一条记录，不代表一个招聘名额。
- 唯一身份：`source, portal, batch_id, source_site, job_id`；`seq`作为快照内便捷键。
- 数据入口：仅 `pending_jobs`，不是指纹表与待同步表拼接；同步出队历史无法从队列恢复。
- `raw_data`保留在原始快照，轻量表不复制；其余payload顶层字段展开。
- `source/job_id/batch_id/source_site`与队列身份不一致时停止，避免静默覆盖。
- 快照时间是数据保存时间；入队时间是系统处理时间；发布日期是官网字段，三者不可混用。

## 清洗规则

| 内容 | 规则 | 限制 |
|---|---|---|
| JSON | 非对象、无法解析者隔离并记录seq | 不自动修复正文 |
| 文本 | HTML实体还原、去标签、合并空白；保留原列 | 不删除完整业务句子 |
| 地点 | 支持字符串/列表/字典；分隔符拆分；部分英文别名映射；去城市后缀 | 不是完整地理编码库 |
| 城市列表 | 每职位内去重；省级/地区、范围/国家、区县和复杂待核验标签单独标记 | 其余为“城市候选”，仍需人工审核 |
| 日期 | UTC解析，失败留空 | 不自动当作采集日期 |
| 学历薪资 | 保留原缺失，不填0 | 不直接做跨公司薪资排名 |
| 复杂类型 | 写Parquet前序列化为JSON字符串 | 下一课用json.loads显式还原 |

## 统计指标

| 指标 | 分子 | 分母/单位 |
|---|---|---|
| 公司职位数 | 公司不同job_key数 | 条 |
| 公司样本占比 | 公司职位数 | 全部职位数 |
| 公司内招聘类型占比 | 公司某类型职位数 | 该公司全部职位数 |
| 城市岗位覆盖数 | 含某城市的不同job_key数 | 条；不同城市可重复覆盖同一职位 |
| 城市覆盖率 | 城市岗位覆盖数 | 全部职位数，包括无城市候选者 |
| 公司城市覆盖率 | 公司在该城市的职位数 | 该公司全部职位数；行合计可超过100% |
| 字段覆盖率 | 非空或成功解析记录数 | 对应公司职位数；不等于准确率 |
| 全文技能提及率 | 职责或要求命中的职位数 | 全部职位数/明确指定子集数 |
| 要求技能提及率 | 任职要求命中的职位数 | 有任职要求文本的职位数 |
| 技能共现数 | 同时提及两技能的职位数 | 条；对角线=单技能提及数 |

统一招聘类型来自payload的 `recruitment_type`，保留society/campus/graduate/internship/
regular_intern/research_intern/dispatch七类编码，不根据标题覆盖原始类型。

## 文本衍生字段

- `skill_*`：职责或要求命中词典，0/1。`req_*`和`desc_*`分别统计任职要求与职责。
- `skill_count`：命中的词典技能类别数，可能重叠，不是个人技能评分。
- `text_length`：合并清洗正文并去两端空白后的字符数。
- `experience_years_min`：仅抽取明确的阿拉伯数字+年+经验；区间取下界；“不限”记0；上限表达不充当最低要求；不识别复杂中文数字与英文表达。
- `degree_text`：只提取带要求语境的中文学历，按大专、本科、硕士、博士顺序寻找最低层级提示；未识别为“未抽取”，不是无要求。
- `focus_candidate`：标题命中数据分析、数据科学、数据挖掘、商业分析、商业智能、Data Analyst/Scientist、Business Intelligence。不是完整人工职业分类。
- 技能词典及正则集中在 `course_utils.SKILLS`，共18类；SQL明确含MySQL等别名，Java不匹配JavaScript，NoSQL不算SQL。

## 模型与验证

| 项目 | 口径 |
|---|---|
| 第3课关键词 | jieba分词；自定义词与停用词；min_df=5,max_df=.85,max_features=3000；平均TF-IDF |
| 第4课子集 | focus_candidate且正文至少40字符；中文字符占字母/汉字≥30%；同一处理后全文去重训练 |
| 模型输入 | 职责+要求；不直接输入标题、公司、城市；只在明确标记与编号职责间去团队介绍，并去日常实习介绍 |
| 失败基线 | 原文字符2—4元TF-IDF、K=4，观察编号标点与公司模板造成的伪分群，不用于业务结论 |
| 正式表征 | jieba分词、自定义词、套话及公司名停用词；词级TF-IDF，min_df=5,max_df=.8,max_features=4000,sublinear_tf=True |
| 聚类 | KMeans，K=3/4/5/6，n_init=10，max_iter=200，种子42 |
| 选K | 优先最小群≥20且两个种子ARI≥0.6，再取抽样余弦轮廓系数最高者，相同取较小K；无合格方案则回退并明确提示；0.6是教学规则 |
| 距离区别 | KMeans训练优化欧氏距离；余弦轮廓系数是辅助角度相似性诊断，不是同一目标函数 |
| 稳定性 | 同K种子42与43，ARI比较两次分群一致性；不是准确率 |
| 代表样本 | 唯一文本中距离群中心最近的3条 |
| 群技能画像 | 标签映射回全部合格候选职位后，在各群内算提及率 |
| SVD | 唯一训练文本投影到2维，仅可视化；展示解释方差，不用于训练或证明类别真实性 |

本课模型是探索性基线。语言、公司模板和岗位级别都可能影响结果；无人工真值，不报告分类准确率。
不做因果推断，不预测个人录用概率。扩大结论前应增加来源覆盖检查、人工标注和独立验证。
正式模型仅讨论中文为主子集，英文为主的候选保留在原特征表并单独报告排除数。

## 注释增强版：新增字段与比较实验

| 字段/指标 | 定义与范围 |
|---|---|
| `organization_count`（演示底稿） | 组织关系先按完整职位身份聚合，再一对一关联；关系条数不是招聘人数 |
| `fractional_jobs` | 每职位每城市按1/该职位城市数分摊；无城市职位单独保留；不是观测到的人数分布 |
| 来源HHI | 各公司样本占比平方和；只描述样本来源集中度 |
| 标准化北京覆盖率 | 限社招/校招且每公司每类≥30；按入选样本共同类型权重加权，不作因果解释 |
| `role_hints_json` | 标题命中的全部规则提示，JSON数组字符串；规则优先商业/经营、数据挖掘、数据科学、数据分析 |
| `role_hint_primary` | 上述规则的首个提示；没有命中为其他/未识别；不自动改变focus_candidate |
| `title_internship_hint` | 标题含实习、intern或internship，保留为文本线索 |
| `internship_hint_outside_intern_type` | 标题有实习提示但编码不在三种明确实习类型内；对照标记，不等于源数据错误 |
| `req_context_Python/SQL/Excel` | 任职要求的语境提示：未提及、否定提示、加分提示、明确要求提示、仅提及、多种语境 |
| `req_evidence_Python/SQL/Excel` | 上述命中前后最多各16字符的片段，合并截取至250字符，供人工检查 |
| 技能长表 | 限标题筛选的数据相关候选；每行一条职位—技能命中关系，不重复计算为新职位 |
| Jaccard | AB共现数/(A数+B数-AB数)，衡量命中集合重叠 |
| Lift | AB数×候选职位数/(A数×B数)，不代表因果或显著性；展示时共同≥20、各自≥30 |
| `cluster_distance` | 到最近群中心的欧氏距离，不是概率 |
| `cluster_distance_gap` | 第二近中心距离减最近距离；小差值用于挑选边界样本，不是校准置信度 |
| 表征ARI | 同一候选的词级文本聚类与8项技能0/1聚类一致性；不是准确率或随机种子稳定性 |
| 文本检索余弦相似度 | 固定词表与IDF，把查询转为向量，与候选文本计算余弦；去掉相同正文后取Top8 |

语境规则按句号、分号、逗号分片，否定优先，其次加分，再看匹配点前的要求提示。
对修饰范围、远距离否定、复杂并列、英文语法没有完备处理；输出保留“提示”名称和证据，不能当可靠硬门槛标签。

## 监督学习课后实验

- 标签：中文为主数据相关候选中的原入口编码 `campus/society`，不是正式/实习身份或个人录用结果。
- 划分：GroupShuffleSplit，按处理后相同正文分组，25%组留出，种子42；实际行比例可能不恰好25%。
- 输入：正文，不直接输入入口标签、公司、城市；独立Pipeline只在训练集fit词表和IDF。
- 表征：词级TF-IDF，min_df=3,max_df=.9,max_features=3000,sublinear_tf=True。
- 分类器：LogisticRegression，max_iter=500,class_weight=balanced,random_state=42。
- 基线：DummyClassifier，始终预测训练集最多的类别。
- 评估：Accuracy、Macro-F1、逐类precision/recall/F1、混淆矩阵、测试预测底稿。
- 限制：防止完全相同文本跨集合，不保证近似模板无泄漏；只验证同快照留出，不代表跨公司/未来泛化。
