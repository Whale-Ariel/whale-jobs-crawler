**《用 Python 分析互联网招聘市场：从原始职位数据到技能画像与岗位聚类》**。

4 节课共 6 小时，建议围绕一条主线推进：**哪些公司在招聘什么岗位、不同岗位需要哪些技能、如何根据技能找到相近的岗位群？**

课程使用当前数据库中的约 4 万条职位记录。教学目标是让学生完成一次可复现的分析，并交付 Notebook、图表和简短报告。考虑课时，适合已有少量编程经验的学生；完全零基础的学生需要提前完成 Python 环境与基础语法练习。

**一、课程要回答的业务问题**

把你构想的内容扩展成五组递进问题：

1. **市场概览**：数据覆盖哪些公司、城市和招聘类型？哪些岗位类别数量较多？
2. **结构差异**：不同公司、城市、社招与校招的岗位结构有什么差别？
3. **技能需求**：技术、产品、运营等岗位分别强调哪些工具、能力和经验？
4. **细分画像**：同名岗位的要求是否相似？不同城市的同类岗位有哪些差异？
5. **岗位聚类**：不依赖职位名称，仅根据职责和要求，能否发现相近的岗位群？

需要贯穿课程强调：这是一份**多公司官网采集样本**。岗位数量代表样本中的职位发布数量，不能直接等同于招聘人数或整个就业市场的需求。

**二、4 节课的简单大纲**

| 课次 | 主题与时间安排 | 核心实践 | 当堂成果 |
|---|---|---|---|
| **第 1 课：理解问题，把数据库变成分析表** | 数据分析与问题定义 15 分钟；Python / Pandas 必要知识 25 分钟；SQLite 与 JSON 拆解 35 分钟；质量检查 15 分钟 | 只读连接数据库；读取 `pending_jobs`；用 `json.loads`、`pd.json_normalize` 展开 `payload`；检查缺失、重复及字段类型 | 一张可分析的职位明细表、一份数据质量概览 |
| **第 2 课：用可视化回答招聘结构问题** | 分析口径与衍生字段 15 分钟；分组聚合 25 分钟；图表实践 35 分钟；结论表达 15 分钟 | 公司与城市分布；社招/校招对比；岗位类别结构；公司×城市交叉分析 | 4—6 张图表及对应结论 |

**三、每节课值得补充的重点**

**第 1 课：除了“拆开 JSON”，还要讲清楚一行代表什么。**

Python 基础控制在课程实际需要的范围：列表、字典、函数、JSON、DataFrame、筛选、缺失值处理和 `groupby`，避免挤占项目实践时间。

数据整理重点包括：

- 用完整职位身份键检查重复，不能只看 `job_id`。
- 保留原始字段，再生成清洗后的分析字段。
- 区分“字段缺失”和“岗位没有要求”，例如薪资为空不能填成 0。
- 处理多城市职位，明确采用“每职位计一次”还是“按城市展开计数”。
- 保留来源、批次、站点和采集时间，方便回溯。

课堂使用只读快照或教师提前导出的数据，避免采集、同步过程改变课堂数据。

**第 2 课：把“画图”升级为“带着问题选图”。**

建议安排以下图表：

| 分析问题 | 图表 | 学习重点 |
|---|---|---|
| 哪些公司发布的岗位最多？ | 排序条形图 | 数量比较与样本覆盖 |
| 岗位集中在哪些城市？ | Top 城市条形图 | 多城市计数口径 |
| 不同公司招聘结构有什么差别？ | 百分比堆积条形图 | 区分数量与占比 |
| 各公司主要在哪些城市招聘？ | 公司×城市热力图 | 交叉分析 |
| 不同岗位类别强调什么学历？ | 分组条形图 | 缺失值与分母选择 |

每张图要求学生写出“**现象＋数字证据＋解释边界**”。时间趋势可以作为拓展内容：先验证发布日期是否完整、各来源口径是否一致，再决定是否分析。

**第 3 课：采用“技能词典＋TF-IDF”的双路径。**

技能词典更易解释，TF-IDF 用于探索未预先列出的词。可以生成这些新列：

| 新增列 | 示例 |
|---|---|
| `skill_python`、`skill_sql` | 是否明确提及该技能 |
| `skill_machine_learning` | 是否提及机器学习相关技能 |
| `skill_communication` | 是否提及沟通协作能力 |
| `skill_count` | 命中的技能种类数 |
| `experience_years_min` | 从明确表述中提取的最低经验年限 |
| `degree_text` | 从任职要求提取的学历要求 |
| `text_length` | 清洗后的文本长度 |

要讲清楚：**未提及某项技能，不代表岗位不需要这项技能**。技能词典还应处理大小写、同义词和词边界，例如避免把 `JavaScript` 误判为 `Java`。

学生可以进一步回答：“在数据分析岗位中，哪些技能经常一起出现？”“同类岗位在不同公司的技能提及率有什么差异？”

**第 4 课：聚焦一个岗位大类，提高结果可解释性。**

建议从“数据相关岗位”中选择一个经人工抽查确认的子集，使用：

**职位职责与要求 → TF-IDF → KMeans → 关键词和代表职位 → 人工命名岗位群**

重点放在结果解释，而不是算法公式。可以比较几个聚类数量，结合轮廓系数、群体规模和代表文本判断结果。

最终让学生检查：这些群是否可能对应不同的工作方向？各群强调哪些技能？主要分布在哪些公司和城市？这些名称都应来自实际结果，不能预先写成课程结论。

**四、建议交付物**

为了让项目真正能展示，建议统一要求学生提交：

- **1 份可复现 Notebook**：覆盖数据读取、清洗、分析、文本特征和聚类。
- **2 张分析数据表**：职位分析明细表、技能与聚类特征表。
- **4—6 张核心图表**：每张附带一句有数据支撑的结论。
- **1 页项目报告**：业务问题、方法、三条发现、局限性。
- **1 份 README**：数据来源、运行方法和字段口径。

教师最好提前提供环境、读取模板、中文字体、初版技能词典和聚类代码骨架。这样学生能在 6 小时内把重点放在分析与解释上。

**五、用 STAR 法概括课程项目**

以下是**完成课程后可按实际成果修改的模板**：

| STAR | 项目概括 |
|---|---|
| **S：背景** | 多家公司招聘官网的数据格式不同，职位职责和任职要求主要以非结构化文本保存，难以直接比较岗位分布与技能需求。 |
| **T：任务** | 基于约 4 万条、覆盖 16 家公司的职位采集样本，建立可分析的数据集，识别公司、城市和岗位的结构差异，并探索细分岗位的技能画像。 |
| **A：行动** | 使用 Python、SQLite 和 Pandas 展开 JSON、清洗字段并统一分析口径；通过可视化分析岗位结构；结合技能词典和 TF-IDF 提取文本特征，再用 KMeans 对选定岗位子集进行聚类，并检查代表职位解释结果。 |
| **R：结果** | 交付可复现 Notebook、分析数据表、可视化图表及项目报告，形成经数据验证的岗位分布发现、技能组合特征和细分岗位画像。具体数量与结论按实际完成情况填写。 |

简历中可以压缩为：

**互联网招聘岗位与技能需求分析｜Python / SQL / Pandas / scikit-learn**

- 基于约 4 万条、覆盖 16 家公司的招聘官网职位样本，完成 SQLite 数据读取、JSON 字段展开、数据清洗与分析口径统一。
- 分析公司、城市和招聘类型的岗位结构，结合技能词典与 TF-IDF 提取职责、任职要求中的技能特征，完成可视化展示。
- 使用 KMeans 对 **[实际岗位子集]** 进行聚类，识别 **[实际数量]** 类岗位画像，交付可复现 Notebook 和分析报告，发现 **[一条经过验证的具体结论]**。

简历中的成果以学生实际完成的分析为准；数据来自已有采集项目时，应写“基于采集数据开展分析”，不能写成学生独立完成了爬虫系统。
