# 招聘数据分析课程｜使用指南

当前是**注释增强版**。四本教材补充了关键参数、输入输出和统计含义的中文注释，较长代码按步骤拆分。
扩展内容包括SQL/Pandas对照、关联基数、累计贡献、城市平均分摊、招聘类型构成调整、
技能语境与Lift、文本/技能双表征聚类、相似岗位检索，以及逻辑回归分类的课后实验。
旧版Notebook与其验证结果保存在 `reports/history/v1/`。

四节课，每节90分钟。适合学过少量Python、能理解变量与循环的学生。
完全零基础的学生请先预习列表、字典、函数和基础表格操作。

## 先看哪个文件

1. `notebooks/01_数据分析基础与JSON结构化.ipynb`：基础语法、只读快照、JSON展开、清洗与数据质量。
2. `notebooks/02_招聘结构与可视化分析.ipynb`：公司、招聘类型、城市覆盖和字段质量图。
3. `notebooks/03_职位文本分析与技能特征.ipynb`：18类技能词典、经验/学历规则、TF-IDF和共现。
4. `notebooks/04_岗位聚类与项目交付.ipynb`：聚焦子集、TF-IDF+KMeans、稳定性检查、代表岗位与报告。

每本均包含时间安排、讲解、可运行代码、练习、参考方向和验收条件。
【主线】用于课堂，【拓展】与【课后拓展】用于教师选讲或学生课后；不是要求6小时讲完全部实验。
阅读路线与时间取舍见 `增强版教学路线.md`，常用操作见 `Python与分析操作速查.md`。
这是完整参考版：练习解答已经给出，课堂上可先折叠解答单元，让学生新增单元独立完成。
运行输出已保存，可先读输出；HTML只读版本在 `reports/`，无需启动Jupyter。

## 本机启动

在终端执行：

```bash
cd /Users/luosen/WorkBuddy/JobsCrawler/data_analysis202612
bash scripts/start_jupyter.sh
```

如果安装环境只有执行依赖，先安装界面：

```bash
.venv/bin/python -m pip install 'notebook>=7,<8'
```

为避免选错Python，首次运行Notebook检查其打印的解释器版本。若已有Jupyter使用别的Python，
可注册课程内核：

```bash
.venv/bin/python -m ipykernel install --prefix .venv --name jobs-course --display-name '招聘数据分析课程'
```

选择该内核后按01→04运行，每本点击“重启内核并运行全部”。上一本产出的Parquet是下一本输入。
中途失败时根据错误修复并重跑该本，不要只跳过失败单元。

## 在新机器安装

建议Python3.10或3.11，在课程目录内执行：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-lock.txt
```

若其他平台无法满足锁定版本，可安装 `requirements.txt`，再完整复跑课程并核查输出差异。
中文字体优先Arial Unicode MS、黑体/宋体或Noto Sans CJK SC。没有中文字体时会提示，
需要安装字体后重启内核；不建议忽略缺字警告。

```bash

# 教师修改生成器后，重新生成Notebook（清除旧输出），再执行
```

## 数据安全与空间

- 源数据库以 `mode=ro` 打开，不修改采集系统、不启动云同步。
- SQLite backup API生成固定快照，可包含已提交WAL内容；不要直接复制一个正在写入的`.db`。
- 快照约数百MB，处理表、环境和带图Notebook也会占用空间；建议至少预留2GB。
- 第一次执行建立快照，后续运行验证SHA后复用，绝不自动替换。想分析新数据，应另建课程副本或手工归档旧快照及全部下游结果后再生成。
- `job_key=seq`只保证在这份固定快照里唯一，不是可跨数据库使用的永久业务ID。
- 原始快照和分析明细仅保存在本机。向外分享教学材料前，自行确认数据再分发权限并清除不需要的原文。
